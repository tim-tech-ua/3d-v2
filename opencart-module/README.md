# 3D Configurator — OpenCart 3.0.4.1 module

OCMOD-пакет, який вбудовує 3D-конфігуратор у картку товару OpenCart.

## Що робить

1. Додає у форму редагування товару (в адмінці) перемикач **«3D Конфігуратор: Увімкнено / Вимкнено»**.
2. На сторінці товару у фронті, якщо перемикач увімкнено — під стандартною карткою товара показується блок «3D Конфігуратор»:
   - Карусель з 4 фото товара + кнопка «+360°»
   - Перемикання на 3D-вьюер (Three.js)
   - Вибір тканини / опор / кольору опор
   - Авто-розрахунок доплати за обрані опції

## Встановлення

### 1. Завантажити OCMOD у OpenCart

- Зайти в **Адмінка → Розширення → Інсталятор**
- Натиснути «Завантажити» і вибрати `configurator3d.ocmod.zip`
- Зайти в **Адмінка → Розширення → Модифікатори**, натиснути кнопку «Оновити» (зелена з блискавкою справа вгорі), щоб OpenCart застосував модифікації

### 2. Створити колонку в БД

- Зайти в **Адмінка → Розширення → Розширення**, у фільтрі «Тип» вибрати **«Модулі»**
- Знайти **«3D Configurator»**, натиснути «+» (Install)
- Після переходу на сторінку модуля натиснути кнопку **«Встановити»** — це додасть колонку `cfg3d_enabled` у таблицю `oc_product`

### 3. Завантажити ассети

Скопіювати на сервер у папку **`catalog/view/javascript/configurator3d/`** такі підпапки:

- **`models/`** — `.glb` файли моделей:
  - `ImageToStl.com_Bjorn_Andre_obj.glb` (стартова модель)
  - `asset.glb` (друга модель з колекції)
  - `opora/Bjorn_LC_obj.glb` (опора 1)
  - `opora/Bjorn_LR_obj.glb` (опора 2)
- **`textures/`** — `.png` тканини (квадратні безшовні):
  - `MAGIC_VELVET_2243.png`, `London_03.png`, `Enjoy_New_1.png`,
  - `COVER_83.png`, `Boston_11.png`, `BARREL_04.png`
- **`image/`** — `.png` фото для каруселі та колекції:
  - `01.png`, `02.png`, `03.png`, `04.png` — фото в каруселі
  - `10.png`, `20.png`, `30.png`, `40.png` — фото в карточках колекції

### 4. Увімкнути на товарі

- Зайти в **Адмінка → Каталог → Товари**
- Відкрити будь-який товар → у формі редагування знайти перемикач **«3D Конфігуратор»**
- Поставити «Увімкнено», натиснути «Зберегти»
- Відкрити цей товар на фронті — під стандартною карткою з'явиться блок конфігуратора

## Видалення

1. Адмінка → Розширення → Розширення → Модулі → 3D Configurator → **«Видалити»**.
2. Адмінка → Розширення → Інсталятор → знайти в списку запис «3D Configurator» і видалити.
3. Адмінка → Розширення → Модифікатори → кнопка «Оновити».
4. Колонка `cfg3d_enabled` у `oc_product` за замовчуванням НЕ видаляється — щоб уникнути втрати налаштувань при перевстановленні. Якщо потрібно повне видалення, виконати вручну:
   ```sql
   ALTER TABLE `oc_product` DROP COLUMN `cfg3d_enabled`;
   ```

## Технічні деталі

- **Three.js** підключається з CDN `unpkg.com` через `importmap` — нічого складати не треба
- **CSS** заскоупований під клас `.cfg3d`, не пересікається зі стилями теми OpenCart
- **ID елементів** мають префікс `cfg3d-` / `cfg3d` — мінімум шансів конфлікту з темою
- Модифікатори OCMOD працюють з шаблоном `catalog/view/theme/*/template/product/product.twig` — підходить для будь-якої теми, що базується на стандартному product.twig
- Якщо в темі шаблон сильно змінений, треба буде відредагувати XML-пошук в `install.xml` під цю тему

## Підтримувані версії

- OpenCart 3.0.4.x (тестувалося на 3.0.4.1)
- PHP 7.x / 8.x
- Сучасні браузери з підтримкою ES modules і WebGL
